# Optional model attribution

Content review uses a separately installed local **Qwen3:1.7b** through Ollama. [Qwen model card](https://huggingface.co/Qwen/Qwen3-1.7B), [Ollama package](https://ollama.com/library/qwen3:1.7b). Qwen publishes the model under Apache 2.0. Cutlist does not redistribute or alter these weights. The setup command downloads the selected Ollama package; its digest is used to key review caches. Qwen and Ollama do not endorse Cutlist. Inference is restricted to a loopback server; cloud tags and remote aliases are rejected. Model judgments about humor, completeness and usefulness can be wrong. Transcript quotes and cue IDs are validated, but this is not proof of human editorial quality. No vision/gameplay-action understanding is provided by this text model.

Automatic speech recognition uses **NVIDIA Parakeet TDT 0.6b v2**, trained by NVIDIA and distributed under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/). [Original model and model card](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v2).

The **sherpa-onnx project** produced the ONNX export and int8 quantization used here: [exported model](https://huggingface.co/csukuangfj/sherpa-onnx-nemo-parakeet-tdt-0.6b-v2-int8), [conversion source](https://github.com/k2-fsa/sherpa-onnx/tree/master/scripts/nemo/parakeet-tdt-0.6b-v2). The downloader pins revision `84b478d541cdbf0c296a7ab5f1e20a6f8f998114` and verifies SHA-256. Cutlist does not modify the downloaded weights. NVIDIA and sherpa-onnx do not endorse Cutlist. sherpa-onnx runtime code is [Apache 2.0](https://github.com/k2-fsa/sherpa-onnx/blob/master/LICENSE).

The speech model is English only. Cutlist chunks audio near low-energy pauses, normalizes quiet chunks with bounded gain, and releases the model subprocess after transcription. Recognition and word timestamps can be wrong. No speaker identification or translation is claimed.

The optional **CED-tiny** audio-event classifier is provided through [sherpa-onnx's CED package](https://huggingface.co/k2-fsa/sherpa-onnx-ced-tiny-audio-tagging-2024-04-19), with model and upstream licensing information at that source. The download script retains the actual AudioSet class mapping and verifies every event label used. [CED upstream research/code](https://github.com/RicherMans/CED). Its detection scores are not viewer metrics or calibrated probabilities.

Noto Sans fonts are bundled under the SIL Open Font License 1.1; see `public/fonts/OFL.txt`.

Optional sampled visual context uses **Qwen3-VL:2b** (about 1.9 GB, Q4_K_M) through local Ollama. [Package and Apache 2.0 license](https://ollama.com/library/qwen3-vl:2b), [Ollama image API](https://docs.ollama.com/capabilities/vision). The package requires Ollama 0.12.7 or newer. The worker checks that the installed model advertises `vision` capability. Cutlist sends only locally decoded, timestamped JPEG samples (384-wide ordered sequences; 640-wide legacy overview frames) to the loopback service, validates frame IDs, and unloads vision before text review. Sparse still images do not establish unseen motion, an event outcome, or human emotion. Model observations are labelled predictions. No visual model is bundled or downloaded automatically.

Optional anonymous voice labels use the **3D-Speaker ERes2Net base** ONNX embedding model from the [sherpa-onnx speaker model release](https://github.com/k2-fsa/sherpa-onnx/releases/tag/speaker-recongition-models), filename `3dspeaker_speech_eres2net_base_sv_zh-cn_3dspeaker_16k.onnx`, as demonstrated in [the official CPU diarization example](https://github.com/k2-fsa/sherpa-onnx/blob/master/python-api-examples/offline-speaker-diarization.py). [3D-Speaker upstream and license](https://github.com/modelscope/3D-Speaker). This checkpoint is trained on Chinese speech; grouping quality on English, accents, game audio and overlapping voices is not validated here. Cutlist clusters embeddings within a selected clip, assigning anonymous numbers, not real identities. This is cue-level clustering, not full speaker diarization; a cue containing several voices is not separated. Supplied/manual names are preserved. Weights are downloaded explicitly and validated by the runtime before installation.

Optional face following uses **OpenCV** and its bundled pretrained frontal-face Haar cascade. [OpenCV face detection documentation](https://docs.opencv.org/4.x/db/d28/tutorial_cascade_classifier.html), [licenses](https://github.com/opencv/opencv/tree/4.x). The dependency and detector data are installed only with `npm run tracking:install`. Detection uses CPU on sampled frames within the chosen clip. It tracks a nearby visible face, without identifying anyone or deciding who is speaking; occlusion, non-frontal faces and small webcam overlays can fail. Manual framing remains available.

Optional semantic transcript search uses Google's **EmbeddingGemma 300M** local model through Ollama (approximately 622 MB). [Ollama package](https://ollama.com/library/embeddinggemma), [Google model documentation and terms](https://ai.google.dev/gemma/docs/embeddinggemma), [embedding API](https://docs.ollama.com/api/embed). The model is distributed under the Gemma terms, not the Apache license of the Qwen text model. Its package requires Ollama 0.11.10 or newer. Cutlist checks embedding capability, validates finite vector dimensions, stores resumable index batches locally, and uses semantic similarity to retrieve transcript passages. A separate text-model call checks detailed search intent when available. Embedding similarity is not a probability of quality, humor or virality. Search does not transcribe other languages or supply information absent from its transcript.

Visual sequence review supplies six chronologically ordered low-resolution images around an event anchor, validates all returned frame IDs, and requires a separate visual acceptance pass for a visual-only candidate. Sparse samples still leave unseen action between frames. The optional local preference ranker is small NumPy-based pairwise regression on editor feedback; it does not modify downloaded model weights. It excludes sample/manual examples and evaluates held-out recordings before applying a bounded ranking adjustment.
